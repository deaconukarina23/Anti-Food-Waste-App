# Anti-Food-Waste-App

Aplicatie web pentru reducerea risipei alimentare

## Obiectivul aplicatiei

Crearea unei platforme bazate pe comunitate care promoveaza constientizarea consumului responsabil si faciliteaza schimbul de produse alimentare.

## Functionalitati principale

1. **Lista de alimente**
- utilizatorul adauga produsele alimentare (nume, categorie, cantitate, data de expirare)
- poate vizualiza, sterge, edita sau marca produsele ca disponibile sau donate

2. **Alerte de expirare**
- aplicatia trimite notificari atunci cand un produs se apropie de termenul de valabilitate
- utilizatorul poate marca produsul ca fiind disponibil pentru donatie

3. **Grupuri si prieteni**
- utilizatorii pot crea grupuri (ex: vegetarieni, carnivori, vecini)
- utilizatorii pot vizualiza alimentele disponibile la prieteni
- utilizatorii pot invita prieteni si filtra dupa preferinte alimentare

4. **Solicitare de produs (claim)**
- orice utilizator poate solicita un produs disponibil
- proprietarul poate accepta sau refuza cererea
- dupa confirmare, produsul e marcat ca donat

5. **Integrare social media**
- utilizatorul poate distribui produsele disponibile pe Instagram si Facebook
- link public pentru vizualizarea produsului

## Tehnologii utilizate

**Frontend:** React.js - pentru realizarea interfetei aplicatiei
**Backend:** Node.js + Express - pentru logica aplicatiei si API-ul REST
**Baza de date:** MySQL - pentru stocarea informatiilor
**ORM:** Prisma - pentru legatura intre cod si baza de date
**Versionare:** Git + GitHub - pentru salvarea si urmarirea modificarilor

## Plan de dezvoltare

1. Analiza: stabilirea scopului si a functionalitatilor de baza
2. Backend: crearea serverului cu Node.js si conectarea la baza de date
3. Frontend: realizarea interfetei web in React si legarea cu API-ul
4. Testare: verificarea functiilor principale si pregatirea prezentarii finale

## Concluzie

Este o aplicatie web care ii ajuta pe utilizatori sa reduca risipa alimentara printr-un sistem simplu de gestionare a produselor. Proiectul imbina partea tehnica (frontend + backend) cu un scop social si ecologic.
